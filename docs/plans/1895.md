# #1895: Wire the console Shamir form to ceremony initialization

## Objective

Codex review 7420 P1 6 on #1845: the Barrier view's uninitialized Shamir
form calls `BarrierClient.initializeShamir`, which the system barrier
refuses once the go-qrdb re-pin lands (`SystemShamirInitRefusedError`).
The form must run the initialization ceremony instead, so a browser
operator can bootstrap a fresh system Shamir barrier.

## Where main stands

- Main still pins go-qrdb v0.30.1-alpha (the re-pin is #1816/#1389, held),
  so the refusal is not on main yet; the bare init still returns the raw
  shares to the browser.
- Main's SDK already has `CeremonyClient.initialize` (POST
  `/api/v1/init/initialize`: threshold, SO PIN, user PIN, officers with
  username + CSR PEM). The fix needs no SDK or server change.

## Slices

1. Barrier view runs the ceremony
   (`cmd/quicbaas/frontend/src/views/security/BarrierView.svelte`):
   the form takes the threshold, the SO and user PINs and the officer
   list (username + CSR PEM, add/remove rows) and calls
   `CeremonyClient.initialize`; the result reports the ceremony state and
   the share count (shares are sealed to the officers, none reach the
   browser); errors render in the form.
   Tests (`cmd/quicbaas/frontend/test/BarrierView.test.ts`):
   - the uninitialized form shows the PIN and officer fields, no
     "Total shares";
   - submitting POSTs `/api/v1/init/initialize` with the threshold, PINs
     and officers, never `/api/v1/barrier/shamir/initialize`, and shows
     the share count;
   - a server error renders in the form.

## Out of scope

- The go-qrdb/go-xkms re-pin that brings the refusal (#1816, #1821).
- The `admin_csr_pem` field of the re-pinned SDK: main's ceremony request
  has no such field; the re-pin's lane carries it.
- Removing `init` from the svelte-security `BarrierClient` contract
  (`TenantBarrierView` and the package's components are outside this row).
- A Playwright E2E test: needs a daemon with a Shamir system barrier;
  the vitest test drives the view against the SDK's REST client.
