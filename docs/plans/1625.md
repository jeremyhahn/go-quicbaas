# Plan: #1625, sdk/grpc route parity (no raw Invoke fall-through)

## Objective

Every `sdk/go` client service reaches the server over the SDK gRPC
transport (`sdk/go/transport/grpc`) and so over the Unix transport, which
delegates to it. No service name may reach the raw
`conn.Invoke("/" + service + "/" + method)` fall-through in
`Transport.doRequest`: that sends a plain Go struct under the SDK service
name, which no server registers, so it fails every time.

## State on main (2026-11-13)

Routed since the ledger (comment 125220): ParameterStore, TimeSeries,
ObjectTransfer, ObjectStorageAdmin, DEK, the Auth session verbs and the
IAM lookup verbs (trains dh, di). Still falling through: Backup, Cache,
ObjectStorage, Ollama, Query, ACME.

## Slices, in order

Each slice folds the preserved tip when one exists (CA order: fold first,
with history), and adds a test that drives the real client over the gRPC
transport against an in-process server, plus one for the error path.

1. **Backup and Cache** (fold `issue/1621d`). `backup_handler.go`,
   `cache_handler.go` on the QuicBaaS proto. Tests:
   `TestBackupHandler_*`, `TestCacheHandler_*` (every verb carried,
   server refusals mapped, unknown verbs and request types refused).
2. **Ollama**, except `IsAvailable` (fold `issue/1621i2`).
3. **ObjectStorage** unary verbs, then the streams (fold `issue/1621s`).
4. Methods the routed handlers do not dispatch (ledger table 2): Crypto
   batch, Secrets version and rotation policy (`issue/1621e`),
   Orchestrator task artifacts (`issue/1621k`), Batch and Transaction
   (`issue/1621n`), Certificate refusals (`issue/1621f`), each checked
   against main first: several are already routed.
5. A guard test: every `serviceName` under `sdk/go/client/` is claimed by
   an `is*Service` check, so a new service cannot fall through silently.

## Out of scope (needs a coordinator ruling)

- ACME: no proto at all.
- `Query.Execute`: no unary RPC; `QuicBaaS.Query` is a server stream of a
  different shape.
- Ollama `IsAvailable`: no RPC.

These stay refused, typed, until ruled on.
