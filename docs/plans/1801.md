# #1801 — bootstrap / IAM: every backend's first-boot admin authenticates

## Objective

TestBackendMatrix and TestCanonicalInit_Matrix prove, on every storage
engine (memory, file, pebble) and every transport (rest, grpc, quic, mcp,
unix), that the administrator first boot issued can authenticate: the SDK's
Health.Liveness and a data round trip, with no backend special-cased.
go-qrdb's MCP server refusing an uncredentialed initialize stays (CA ruling
571); first boot stays go-qrdb's (rulings 538, 539).

## Slices

1. Test harness (done): the memory skip rested on a wrong premise (a memory
   node runs the same qrdb first boot in `quicbaasd start`). Every `*_mcp`
   cell failed because MCP was dialled without a credential.
   `loginFirstBootAdmin` logs in as the first-boot admin (on REST for an MCP
   cell: MCP needs a credential first); `newSDKClient` /
   `verifySDKLivenessOverTransport` present the token over MCP.
   Test: TestNewSDKClient_MCPPresentsAdminToken.
2. MCP data put/get (this slice): `data put` over MCP failed with
   "mcp.callTool: key is required". On the composed node `qrdb_put/get/
   delete/list` are go-qrdb's native raw-KV tools (`key`/`value`); quicbaas's
   entity-KV tools of the same name are left out of `ModuleTools` as
   duplicates, so the SDK's entity arguments (`entity_type`, `id`, `data`)
   reached go-qrdb's tool. BLOCKED on a ruling (shepherd: an alias may
   only map onto an existing go-qrdb tool and its permission, no new
   permission). (a) quicbaas's entity-KV verbs as `quicbaas_kv_put/get/
   delete/list` on the module surface (names already in the CLI help and
   docs/mcp-server/cli.md) adds four MCP tool permission registrations
   (kv:put/get/delete/list); (b) the SDK sending go-qrdb's `key`/`value`
   shape must rebuild quicbaas's keyspace (`__t:{tenant}:{type}:{id}`)
   client-side: duplicate logic (ruling 538), and go-qrdb's own tenant
   scoping may not match it, splitting data across transports.
   Tests once ruled: the SDK KV verbs call the ruled tool (fails first);
   `make integration-test-init`: every `*_mcp` cell past data put.
