# Plan: SPEC row `embeddings` (#1671)

## Objective

Make the SPEC row `embeddings` hold as `docs/SPEC.md` states it:

1. go-qrdb's embedding service (`transport.EmbeddingClient`) is re-exported
   through `sdk/go`, so a QuicBaaS SDK consumer reaches it without importing
   `go-qrdb/sdk/go`.
2. QuicBaaS's own embedding service (`sdk/go/client/embedding`, `pkg/embedding`)
   stays as a parallel implementation until the owner says to remove it.
3. Providers Ollama, OpenAI, Voyage and LM Studio are each reachable.

Detail: `docs/embeddings/`.

## Slices, in order

1. **Re-export (`sdk/go`).** In `sdk/go/qrdb.go`: type aliases
   `QRDBEmbeddingClient`, `QRDBEmbedRequest`, `QRDBEmbedResponse`,
   `QRDBBatchEmbedRequest`, `QRDBBatchEmbedResponse`,
   `QRDBListEmbeddingModelsResponse`, `QRDBEmbeddingModelInfo`, and an
   accessor `AI().QRDBEmbedding() (QRDBEmbeddingClient, error)` that returns
   the qrdb sub-client's `Embedding()`, or an error when the qrdb client cannot
   be built or its transport has no embedding surface.
   Tests (`sdk/go/qrdb_embedding_test.go`): the aliases are identical to the
   go-qrdb types (assignability), the accessor returns go-qrdb's client on the
   REST/gRPC transports, and returns an error (no panic) when the qrdb client
   fails to build. `docs/embeddings/api.md` documents the accessor.
2. **Parallel implementation.** Document in `docs/embeddings/architecture.md`
   that `Embedding()` (QuicBaaS's own service) and `QRDBEmbedding()` (go-qrdb's)
   live side by side, and which one a caller picks; a test pins that both
   accessors exist on `AIService`. Removal waits on the owner's word.
3. **Providers.** A table test in `pkg/embedding` (tags `vector qrdb_vector`)
   that constructs each of Ollama, OpenAI, Voyage and LM Studio against an
   `httptest` server and embeds one text; the provider names are listed in
   `docs/embeddings/user.md`.
4. **Ship.** The row's PR marks the row `shipped` in `docs/SPEC.md`.

## Out of scope

- Removing QuicBaaS's own embedding service (waits on the owner).
- The NPU provider and go-qrdb#528 (`npu` as a configured default).
- A CLI verb for the go-qrdb embedding client.
