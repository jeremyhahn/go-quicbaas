# Plan: SPEC row `ssh` (#1674)

## Objective

Ship SPEC row `ssh` ("SSH through go-xkms"): go-xkms's SSH service re-exported
through `sdk/go`, QuicBaaS's own SSH facade and key store kept as the parallel
implementation until the owner removes it, server-held SSH keys, known hosts
and authorized keys. Detail: `docs/ssh/`. The row's PR closes #1674 and marks
the row shipped in `docs/SPEC.md`.

## State on main (slice 1 survey)

- Re-export: `sdk/go/client/ssh/types.go` aliases go-xkms's SDK SSH types;
  `sdk/go/client/ssh/client.go` serves them over every QuicBaaS transport.
- Facade and store: `pkg/service/ssh_service.go`, `pkg/server/ssh_store.go`
  (sealed `__sys:ssh/` keyspace), REST/gRPC/QUIC/MCP handlers.
- Keys, known hosts, authorized keys: served on every transport.

## Slices, in order

1. **Fold + Session.Dial (#1092).** Done. Merge `refs/fold/ssh/row/1909-aq1909`
   (SSH workspace cloning keeps host-key pins with remote xkms; its test is
   `TestWireProjectWorkspaces_RemoteXKMSKeepsSSHCloning`). Implement
   `Session().Dial` as go-xkms#719 did: dial from the caller's process with
   the forward-signing `Keys().Signer` and the `KnownHosts().Callback` pin
   check; the server never carries the SSH stream. Tests:
   `sdk/go/client/ssh/client_dial_test.go` (real session against a loopback
   SSH server, pin-scope default and override, fail-closed on unpinned and
   changed host keys, request validation, unreachable host). Docs:
   `docs/ssh/architecture.md`, `docs/ssh/engineering.md`.
1b. **RSA SHA-2 signing.** Done. `SSHSignDigestRequest.algorithm` carried by
   every transport. The SDK forward signer is an `ssh.AlgorithmSigner`, and
   the service signs with the requested algorithm or refuses one that does
   not fit the key (invalid argument). Tests: per transport, plus
   `TestSessionDialNegotiatesRSASHA2`.
2. **#1936: preserve SSH records across the store upgrade.** When the store
   moves to go-xkms's DAO stores (the #1389/#1814 work, go-xkms > v0.49),
   the v0.49 key-value records under `__sys:ssh/` must be imported, not
   dropped (go-xkms#1749 is the import). Test: a node seeded with v0.49
   records boots on the new store and serves the same keys, pins and
   authorized-keys entries. Blocked until main carries that go-xkms bump:
   main still runs go-xkms v0.49.1, whose store reads those records itself.
3. **Ship.** Tick the row's acceptance and folded items, mark `ssh` shipped
   in `docs/SPEC.md`. Marking the row shipped is done on the row's PR.

## Out of scope

- `Console`: needs a persistent byte stream no QuicBaaS transport carries;
  it stays `CodeUnimplemented`, as on go-xkms's gRPC and MCP transports.
- Removing the parallel facade: only on the owner's word.
- The go-xkms version bump itself (its own row/PR).
