# Plan: #1821 login tools public on the composed MCP server

## Objective

`quicbaas_login_begin` and `quicbaas_login_finish` are callable with no
identity on the composed MCP server, as on gRPC and REST. No other tool's
permission changes.

## Status: blocked on the go-qrdb pin

The issue's scope: declare the public tools through a qrdb SDK seam beside
`MCPToolPermissions` (`ModuleMCPPublicToolLister`, go-qrdb v0.51.0-alpha);
if the pinned go-qrdb does not export it, stop and report the missing seam
instead of copying qrdb logic.

On main, go.mod pins go-qrdb and go-qrdb/sdk/go at v0.30.1-alpha (held:
#1389, the go-qrdb/go-xkms stack pin bump). That version exports
`apimodule.GRPCPublicMethodLister` and `apimodule.MCPToolPermissioner`, but
no public-MCP-tool lister. `MCPToolPermissions` can only give a tool a
permission (`IdentityGated` still needs an identity), so the composed gate
cannot be told a tool is public. The old branches issue/1814d and
issue/1817a predate the GitHub move and have no merge base with main.

Main also keeps both login tools refused on purpose
(`pkg/api/mcp/authz_qrdb_unmapped.go`), for two more pinned-SDK reasons:

- login_begin: the pinned SDK neither expires nor caps abandoned login
  attempts, so a public login_begin grows daemon memory without bound;
- login_finish: it needs the verified mTLS leaf, reachable on the MCP
  listener only through go-qrdb#1181's verified-chain seam, absent from the
  pin.

## Slices (after the #1389 pin bump lands a go-qrdb with all three seams)

1. `pkg/apimodule/module_mcp.go`: the module implements the SDK's public
   MCP tool lister from `spec.Public`; `MCPToolPermissions` no longer
   declares public tools. Test: on the composed MCP server,
   `quicbaas_login_begin` succeeds with no identity; a non-public tool with
   no identity is still refused (fails before, passes after).
2. `pkg/api/mcp/authz.go`: add both login tools to `publicTools` and remove
   their two groups from `authz_qrdb_unmapped.go`; put the verified leaf on
   the login_finish context; a test covers abandoned-attempt expiry.

## Out of scope

- The go-qrdb pin bump itself (#1389).
- Any other tool's permission.
