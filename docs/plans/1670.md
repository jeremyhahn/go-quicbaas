# Plan: SPEC row `vector` (#1670)

## Objective

Row `vector` in docs/SPEC.md holds as stated, and its three folded issues
(#1868, #2045, #2055) are fixed with tests. Then the row is marked shipped in
docs/SPEC.md. One branch (`row/1670-vector`) and one PR.

## Slices, in order

1. **Fold #2389 (#1868, part one).** Merge the slice branch. A rebuild keeps
   the namespace's distance metric, and GetRebuildProgress compares scoped
   names. Its tests come with the merge (pkg/service).
2. **#1868, part two: scan Offset and embeddings.**
   - The node's `ScanNamespace` honours `Offset`. It reads every page, sorts by
     ID and slices. qrdb's page order is unstable across calls, so skipping
     during a cursor walk duplicates or drops vectors.
   - The rebuild asks for the embeddings (`IncludeVectors`).
   - Tests: `TestNodeVectorStorage_ScanNamespace_Offset` (pkg/server, e2e
     against an embedded node) and `TestPerformIndexRebuild_PagesWithVectors`
     (pkg/service).
3. **#2055: progress stays in the caller's tenant.**
   - `GetCompactionProgress` finds an operation only under the caller's
     tenant prefix, and answers with the unscoped namespace.
   - The REST index-progress, compaction-progress and compact handlers call
     the vector service instead of returning stub answers. The pkg/apimodule
     handlers are these same REST handlers.
   - Tests: `TestGetCompactionProgress_TenantNamespace` (pkg/service).
     `TestHandleGetIndexProgress`, `TestHandleCompactNamespace` and
     `TestHandleGetCompactionProgress` cover another tenant's job, another
     namespace's job and the success path (pkg/api/rest). The nil-service
     cases now answer 503.
4. **Re-export go-qrdb's vector and HNSW service through `sdk/go`.**
   - `QRDBVectorClient` was already an alias.
   - `sdk/go/qrdb_vector.go` adds aliases for every request, response, result
     and error type the client uses, plus the distance-metric and index-type
     constants (HNSW, flat, IVF-flat).
   - Tests: `TestQRDBVectorReexport_*` (sdk/go). They drive a client written
     only against the re-exported names.
5. **#2045.** UpdateNamespace on REST and MCP refuses instead of answering
   success. This is already on main, with its tests; the row ticks it.
6. **Row acceptance.**
   - QuicBaaS's own vector service, local index and client stay in place
     (pkg/service/vector.go, pkg/interfaces, pkg/rag). The owner has not ordered their removal.
   - Namespaces, search and indexing are covered by the existing unit and
     integration suites.
   - Mark the row `shipped` in docs/SPEC.md and point docs/vector/ at the
     re-export.

## Tests run

`make test-server`, `make test-service`, `make test-api-rest`,
`make test-sdk-go`, `make integration-test-vector`.

## Out of scope

- Removing QuicBaaS's own vector implementation (needs the owner's word).
- New vector features beyond the row's acceptance.
