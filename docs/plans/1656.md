# Plan: SPEC row multi-tenancy (#1656)

## Objective

Ship SPEC row `multi-tenancy`: go-qrdb's tenants and per-tenant barriers
re-exported through `sdk/go` with tenants strictly isolated; QuicBaaS's own
tenant manager and storage kept as the parallel implementation (removed only
on the owner's word); an empty caller tenant never read as the system tenant;
and every share-bearing `tenant barrier` verb with a path off argv. The row's
one PR closes #1656 and marks the row shipped in docs/SPEC.md.

## Slices, in order

1. **#491 / argv path (fold PR #2416).** Merge `dc7eb7d5e` with `--no-ff`:
   `tenant barrier unseal-share --share-stdin` reads the share from stdin;
   `--share` stays as the exposed fallback. Tests: `cmd/quicbaas`
   tenant_barrier_test.go (stdin read, mutual exclusion, empty input) and the
   canonical verb surface test.
2. **Empty caller tenant.** Every tenant-scoped handler and the tenant
   context resolver refuse an empty caller tenant instead of treating it as
   the system tenant. Tests: tenantctx unit tests (empty -> denied), REST and
   gRPC handler tests per transport.
3. **#1522 embedded Tenant/Update.** The embedded transport stores
   DisplayName, Metadata and Status, not only the name. Test: update then
   get round-trips every field on the embedded transport.
4. **#995 root /v1/tenants barrier mount.** Mount the per-tenant barrier at
   the root `/v1/tenants/...` path the go-qrdb transport addresses, so
   `tenant barrier init --transport rest` works. Test: REST router test and
   the tenantbarrier integration target on REST.
5. **#1843 unix TenantBarrierService.** Serve `qrdb.v1.TenantBarrierService`
   on the unix transport for tenant quorum and holder claims (behind
   go-qrdb#1156: blocked until that pin lands). Test: unix transport
   integration of quorum and holder claim.
6. **#1850 CI job.** A CI job runs `make integration-test-tenantbarrier`
   (the seal lane is excluded from the base run). Test: the job runs green.
7. **sdk/go re-export and isolation.** `sdk/go` re-exports go-qrdb's tenant
   and per-tenant barrier types; a cross-tenant test proves tenant A cannot
   read or unseal tenant B. Then tick the row in docs/SPEC.md.

## Out of scope

- Removing QuicBaaS's own tenant manager and storage (owner's word only).
- go-qrdb changes (go-qrdb#1156 is upstream).
