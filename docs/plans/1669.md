# Plan: SPEC row `timeseries` (#1669)

## Objective

Ship SPEC row `timeseries` (docs/SPEC.md): time series through go-qrdb.
Acceptance, from the row:

1. Re-export of go-qrdb's time-series service (`TimeSeriesClient`)
   through `sdk/go`.
2. QuicBaaS's own time-series service and client: a parallel
   implementation, removed on the owner's word.
3. Write, query and retention.

Detail: `docs/timeseries/`.

## Slices, in order

1. **go-qrdb re-export** (slice 1). `sdk/go` already aliases
   `QRDBTimeSeriesClient = qrdbtransport.TimeSeriesClient`, but no public
   entry point returned one. Add `Search().QRDBTimeSeries()
   (QRDBTimeSeriesClient, error)`, backed by the lazily built go-qrdb
   client. On `SearchService` rather than the top-level `Client` interface,
   so the CLI's `Client` mocks are untouched.
   Tests: `sdk/go/qrdb_timeseries_reexport_test.go`: write, query,
   set-retention and get-retention through the re-exported client reach
   go-qrdb's `/ts/*` routes on a stub node; a go-qrdb client that cannot be
   built returns an error, never a nil client.
2. **QuicBaaS's own service and client, audited**. The api.md MISSING
   cells were stale (gRPC Write/Query and embedded Write exist). The real
   gap was retention: `sdk/go/client/timeseries` gains `SetRetention` /
   `GetRetention` (typed `RetentionPolicy`), wired on REST (PUT/GET
   `/api/v1/timeseries/retention/{metric}`), gRPC (`TSSet/GetRetentionPolicy`),
   MCP (`qrdb_ts_set/get_retention_policy`) and embedded, each with a test.
   Done: the api.md matrix is refreshed; the root module builds. Two
   defects found on the way are fixed with tests: embedded `Query` refused
   the SDK's `*timeseries.QueryRequest`, and MCP's untyped
   `GetRetentionPolicy` reader took top-level `*_seconds` fields where the
   server sends a nested policy in ns.
3. **Write, query and retention end to end**. `make
   integration-test-timeseries` covers write, query and retention on every
   transport, through both clients; add the cases that are missing.
4. **Ship**. Update `docs/timeseries/` and mark the row shipped in
   `docs/SPEC.md` in the row's one PR, which closes #1669.

## Out of scope

- Removing QuicBaaS's own implementation (item 2): only on the owner's word.
- Changes to go-qrdb itself.
