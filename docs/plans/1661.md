# Plan: SPEC row certificate-authority (#1661)

## Objective

Serve the certificate authority only through go-xkms: `sdk/go` re-exports
the go-xkms CA (`CAService`, `TCGCAService`) on every transport, device
identity is issued by the go-xkms CA (`IssueDeviceIdentity` returns the IAK
certificate), QuicBaaS's parallel certificate service is removed on the
owner's word, and trust anchors are served. Detail: `docs/certificate-authority/`.
