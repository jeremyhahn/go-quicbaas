# Plan: SPEC row certificate-authority (#1661)

Objective: the certificate authority is go-xkms's, served by QuicBaaS only as
go-xkms re-exports through `sdk/go` on every transport; QuicBaaS's parallel
certificate implementation goes on the owner's word. Detail:
`docs/certificate-authority/`. One branch `row/1661-certificate-authority`,
one PR (#2450).

## Slices, in order

1. Folds. Merge PR #2384 (`fold/sdk-transports-d`) with `--no-ff`; account
   for every `refs/fold/certificate-authority/*` ref (merge, pick or drop,
   with a trailer). Tests: the unit tests of every package the merges touch.
2. #2073 / #1826: `sdk/go/xkms/ca` re-exports `NewParentCA`,
   `NewIntermediateCA` (landed via #2405) and `ca.Params.RevocationStore`.
   Test: a compile-and-call test in `sdk/go/xkms/ca`.
3. #2029: certificate listing returns the `IsRevoked` error instead of
   listing the certificate as not revoked. Test: a store whose IsRevoked
   fails makes List fail.
4. #2069 / #2070: the MCP xkms save-certificate tools take the system
   key-store writer guard REST applies; Chain's AIA import requires
   `trust:write` on every transport. Tests: per-transport permission tests.
5. #1823: DANE publish and AIA auto-import take the go-xkms #1674
   permission at the go-xkms re-pin. Test: permission denied without it.
6. Device identity: `IssueDeviceIdentity` issues through the go-xkms CA in
   the system tenant (#1893 fold) and returns the IAK certificate. Test:
   the returned certificate is the IAK one, issued by the go-xkms CA.
7. Re-export `CAService`, `TCGCAService` through `sdk/go` on every
   transport (#1330), with `make integration-test-<feature>` per transport.
8. Trust anchors, then, on the owner's word, remove QuicBaaS's own
   certificate service, CA adapters, SPIFFE SAN/device-identity logic,
   `/api/v1/certificate` verbs and the second datastore in
   `pkg/server/lifecycle.go`. Last: mark the row shipped in docs/SPEC.md.

## Out of scope

- Changes inside go-xkms itself (they land there and arrive by re-pin).
- The removal in slice 8 before the owner's word.
