# #2741: a system admin acts for a named tenant over gRPC Federation and the MCP IAM tools

Draft for the owner's decision; not merged without it.

## Objective

Over REST a system-tenant caller that names another tenant on the IAM
administration routes acts in it (`pkg/api/rest/tenant_target.go` urlTenant,
`tenantctx.AdminTarget`). Over gRPC Federation and the MCP IAM tenant-scoped
tools the same caller is refused (`tenantctx.Target`), which fails 37
Integration subtests (run 45558569441) on gRPC, unix and MCP. Apply the same
`AdminTarget` rule on those two paths and bind the resolved tenant on ctx.

## Slices (one commit)

1. gRPC: `requireAdminTarget` next to `requireCallerTenant`
   (`pkg/api/grpc/tenant_target.go`) calls `tenantctx.AdminTarget` and returns
   the bound ctx; the eight tenant-scoped Federation RPCs use it and pass the
   ctx on. Every other service keeps `requireCallerTenant`.
   Tests: `tenant_target_test.go` (helper: system lifts, tenant naming another
   refused, own/none acts in own, unbound refused) and
   `server_iam_federation_test.go` (every Federation RPC: system caller reaches
   the manager with ctx bound to the named tenant; own tenant works; another
   tenant and unbound refused before the manager). The Federation row leaves
   the refuse-all table in `TestTenantScopedServers_...`.
2. MCP: `scopeIAMTenant` (`pkg/api/mcp/tools_iam_exec.go`) calls
   `tenantctx.AdminTarget` for `iamTenantScopedTools` and returns the bound
   ctx; `executeIAMTool` runs the tool with it.
   Tests: `tools_iam_tenant_test.go`: the system-refusal test becomes
   `TestIAMTools_SystemCallerActsInTheNamedTenant` (arg and ctx bound to the
   named tenant); cross-tenant, unbound and own-tenant tests unchanged.

## Out of scope

- `tenantctx.Target`/`AdminTarget`, REST, any other gRPC service or MCP family.
- RBAC, authz mappings, permission lists. Note for the owner: REST also runs
  `authorizeTenantLift` (a second decision in the named tenant); this draft
  applies the tenant binding only, as the brief decided.
