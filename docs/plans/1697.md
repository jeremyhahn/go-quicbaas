carries no private host, path or lab value; every `docs/` folder meets the
documentation rules; go-xkms re-exports are documented once, in go-xkms;

for. One branch, one PR (#2461).

## Sleep sweep in the files this PR changes

Done: pkg/cache (expiry by backdating entries, `expireNow`), mock_l2,
pkg/rag/watcher event_test (event order instead of 1s windows), pkg/ha
partition (counted probes), pkg/cluster info, pkg/security coverage and
encryption, pkg/service objectstorage_admin, pkg/util/retry (cancel inside
the attempt), pkg/ollama (handlers block on the request context),
pkg/api/websocket/subprotocol stomp (SUBSCRIBE waits on its RECEIPT),
pkg/messaging hub (the duplicate-register test waits on client-2's own
acknowledgment), pkg/iam storage_pool (connections age by a test-only
clock skew, `ageSkew`; health checks are polled) and pkg/iam
batch_processor (tests wait for the stored operation to finish; the
benchmark's per-iteration sleep stays), pkg/watchbridge (counters and
published messages are polled) and the sdk/go/transport/grpc pool tests
(expiry by backdating `createdAt`, the health-check loop polled). Kept:
the end-of-benchmark sleep in BenchmarkWatchBridge and the connection hold
in TestPool_ConcurrentAccess; neither waits on background work. The sleep in
pkg/service/embedding_service_test.go is simulated provider latency, the
thing the test measures, not a wait. The repo-wide sweep is #448 slices
2-5, and the SPEC row gains no sweep line (see Out of scope).
