# Plan: SPEC row `barrier` (#1650)

## Objective

Deliver the `barrier` row of `docs/SPEC.md`: go-quicbaas carries go-qrdb's
system barrier as a re-export, served on all six transports, with no seal
service of its own; barrier secrets never sit in plain strings or forced argv;
the never-served share verbs are gone. The row's one PR (`row/1650-barrier`)
closes #1650 and marks the row shipped.

## Slices, in order

1. **Re-export complete** (acceptance 1). Every type in a go-qrdb
   `BarrierClient` signature has an `sdk/go` alias (the missing
   `ShamirSealVote` request and response added). Test:
   `sdk/go` `TestQRDBBarrierClient_EveryVerbReexported` walks the interface's
   method set, fails on a verb missing from its table and on a signature type
   that is not the alias.
2. **No parallel seal service** (acceptance 2, 3, #1559). `pkg/service`
   `BarrierService` drops its own result types for go-qrdb's; every transport
   reaches the barrier through `Security().Barrier()`. Test: the transport
   parity test in `pkg/server` covers each verb on REST, gRPC, QUIC, MCP, Unix
   and embedded.
3. **init-shamir removed** (#1830, ruling 142 (a)): proto, REST, gRPC, MCP,
   CLI, Go and TS SDK. Test: each transport answers the removed verb as unknown.
4. **Never-served share verbs removed** (acceptance 6, #1497): list shares,
   delete share, delete all shares, verify, from `barrier.proto`, the sealed
   window allowlist and `sdk/typescript`. Test: sealed-window allowlist test
   and TS SDK test without them.
5. **MCP enable-encryption contract** (#1465): the standalone decoder takes
   the qrdb tool's arguments. Test: decoder round-trip with the SDK encoder.
6. **Protected memory** (acceptance 4, #237): shares, recovery keys and
   SO/User PINs held in wipeable buffers in the CLI and service. Test: wipe
   after use.
7. **Off argv** (acceptance 5, #226): `--so-pin` / `--user-pin` and the
   passphrase have a non-argv path (env and a `--*-file`, since a command has
   one stdin). Test: CLI flag-resolution tests; integration on every transport.
8. **Quorum proofs bind the challenge purpose** (#1822). Needs the go-qrdb /
   go-xkms purpose-bound verify; if no tag carries it, a seam row is reported.
9. **Ship**: `docs/barrier/` updated, the row marked shipped in `docs/SPEC.md`.

## Out of scope

- The per-tenant barrier (`multi-tenancy` row), including
  `tenant barrier unseal-share` off argv.
- Barrier logic itself: go-qrdb owns it.
