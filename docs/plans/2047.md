# Plan: #2047, the Object storage navigation item

## Objective

Write the Object storage top-level navigation item into docs/SPEC.md and
ROADMAP.md as a Post dev complete row (owner item 175, ruling 251; split from
#1949, Gitea #1945 / #2043): create and delete buckets; upload, delete and
rename files and folders; pre-signed URLs for external upload and download;
bucket permissions. Drafted from docs/object-storage/architecture.md and
docs/desktop-gui/architecture.md, with those sources cited.

## Slices

   (every new link is a relative link to an existing file or anchor).
