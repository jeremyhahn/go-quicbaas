# Plan #2512: carry the seven open main-fix PRs on one branch

## Objective

Integration has been red on main since 2026-11-14. Each non-cluster failure
has its own fix PR, but none can go green alone because the others still fail
on main. This branch starts from main 5fe3c867 and merges all seven PR heads,
so that one PR's Integration run shows every one of those failures fixed.

## Review fixes on the carry branch

Commits made on this branch after the slice merges, each answering one
review finding:

- 9256f5f5c7 fix(crypto): reserve one AEAD operation per batch item.
  Finding: EncryptBatch/DecryptBatch recorded one operation per batch, so a
  batch could exceed the MaxOperations single calls honour.
- 11eb39bb70 fix(kms): restart AEAD usage for a rotated key's new version.
  Finding: rotation left the old version's exhausted counter in place, so a
  rotated key stayed blocked.
- 2d4d17f38e fix(sdk/mcp): send KV shard as the shardID the entity tools read.
  Finding: KV arguments spelled ShardID as shard_id, which the entity tools
  ignore, so every KV verb used the default shard.
- 50495ae5c3 + 49d9e8f0b4 fix(orchestration): per-build-lifetime build-ID
  references. Finding: runtimes sharing one engine shared the
  quicbaas-build-id:<digest> tag, so one runtime's release or refused-tag
  cleanup could delete an image another runtime still used.
- ecb29ed243 fix(workerimage): release a newly built candidate that fails its
  checks. Finding: candidate() returned an error after BuildImage succeeded
  without releasing the ID it built.
- fix(crypto): the disabled-version guard reads replicated status, fails
  closed, and Decrypt reports the ciphertext's version (two-node and
  rotation tests in crypto_version_status_test.go).
- fix(scheduler): index reconciliation runs in a budget, never fails a
  sweep or open, and resumes (latency-injected reconcile_budget_test.go).
- fix(kms): version status updates read the replicated status. Finding: a
  stale cache made a disable or enable a silent no-op.
- fix(kms): the key backend follows another node's rotation. Finding: a
  node's backend kept sealing under the exhausted old version.
