# Plan #2512: carry the seven open main-fix PRs on one branch

## Objective

Integration has been red on main since 2026-11-14. Each non-cluster failure
has its own fix PR, but none can go green alone because the others still fail
on main. This branch starts from main 5fe3c867 and merges all seven PR heads,
so that one PR's Integration run shows every one of those failures fixed.

## Slices (in merge order)

1. #2492 `fix/main-passkey-fccd22`: TestAdminFactors_PasskeyEnrollsThenLogsIn/rest
   (test/integration/login).
2. #2493 `fix/main-audit-fccd22`: TestAuditEventDelete (pkg/server audit
   logger, test/integration/iam); adds a node_audit_logger unit test.
3. #2494 `fix/main-spawn-fccd22`: TestE2E_RequiredCLISpawn_CloseRemovesTheContainer
   (pkg/orchestration); adds tag-race and container-remove unit tests.
4. #2495 `fix/main-grace-fccd22`: TestKMSGracePeriodWorkflow (pkg/scheduler,
   pkg/service, pkg/api/grpc); adds tenant job index unit tests.
5. #2496 `fix/main-mcp-fccd22`: TestBackendMatrix/memory_mcp (pkg/api/mcp,
   sdk/go/transport/mcp, test/integration/init).
6. #2510 `fix/main-kms-crypto-mount`: TestCLIKMSEncryptDecrypt/encrypt
   (pkg/apimodule).
7. #2511 `fix/main-barrier-grpc-proxy`: TestBarrierStatus/grpc (pkg/server
   barrier proxy).

Each merge is one merge commit. Conflicts are resolved by keeping both
fixes. The five PRs that bump go.mod/go.sum make the same bump, so those
files merge without conflict.

## Verification

- Build, plus the unit tests of every package the merges touch.
- The integration targets of the touched features: login, iam, init,
  kms, qrdb/barrier and fleet_enrollment. The ones that need Docker are run
  by CI.

## Out of scope

- The five cluster tests (TestQRDBCluster_ThreeNodeReplication,
  TestRaftDataReplication, TestRoutingDebugConsistencyAcrossNodes,
  TestTimeSeriesRaft_WriteReplication, TestVectorGRPC_Consistency_SearchResults).
  A separate PR handles them.
- No edits to `pkg/iam/oidc*.go`, the xkms handlers or the platform token
  validator. None of the seven PRs touches them.
