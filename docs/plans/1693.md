# Plan: #1693 — SPEC row desktop-gui: the desktop application and web console

## Objective

Land the desktop-gui row on one branch and one PR (#2458): the console
views, the TypeScript SDK clients they call, and the worker-image fixes the
console's tests need, kept current with main and passing the gates.

## Slices (in order)

1. Keep main merged in (merge commits only). Tests: the unit tests of the
   packages the branch touches (`make test-frontend`, `make test-sdk-ts`,
   the worker-image, `pkg/service` and `pkg/api/rest` Go tests).
2. Account for every unmerged earlier slice kept for this row (below):
   port it, or record why it is superseded or blocked.
3. Port the Certificates and Trust views onto the shared download helper
   (from the 1899 slice). Tests: `test/download.test.ts`.
4. Port the Prompts page (from the 809 slice). Main's SDK carries
   `prompts.ts` but neither exports its types nor wires `Client.prompts`,
   so this slice first wires the SDK on every transport (and rebuilds its
   tracked `dist`), then adds `lib/prompts.ts`, `PromptsView.svelte` and
   their tests. Tests: `PromptsView.test.ts`, `promptsLib.test.ts`,
   `JobDetailView.prompts.test.ts`, `sdk/typescript/test/prompts.test.ts`.
5. Port the tenant Shamir init view to the share-free response (from the
   1888 slice): `TenantBarrierView.svelte` still reads `resp.shares`.
   Tests: `TenantBarrierView.test.ts`.
6. Port the Barrier view's Shamir form onto the initialization ceremony
   (from the 1895 slice). Tests: `BarrierView.test.ts`.
