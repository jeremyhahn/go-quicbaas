# Plan: SPEC row `acme` (#1662)

## Objective

go-trusted-platform reaches the whole go-xkms ACME service (RFC 8555, ARI,
cross-sign, TPM enrollment, device-attest-01) through `sdk/go` on every
transport, by alias; go-quicbaas keeps no ACME implementation of its own once
the owner gives the word. Detail: `docs/certificate-authority/`.

## Slices, in order

1. **device-attest-01 verifier re-export (#1940, part 1).** New package
   `sdk/go/xkms/acme/deviceattest01`: aliases of go-xkms
   `pkg/acme/challenges/device-attest-01` (`Verify`, `VerifyAttestation`,
   `VerifiedAttestation` and its `BindCSRKey`, `AttestationVerifier`,
   `AttestationObject`, `ParseAttestationObject`, the formats, `Setup`,
   `TPMExtraData`, `DICENonce`, the sentinel errors) and the shared
   challenge-validation client. Test: `deviceattest01_reexport_test.go`
   proves each alias is the go-xkms identity (type identity, the same
   sentinel under `errors.Is`, a parse and refusal round trip).
2. **Challenge verifier gets the POST payload (#1940, part 2;
   go-trusted-platform#1093).** go-xkms's `ChallengeVerifierFunc`
   (v0.49.1-alpha) carries no request payload, so this is a go-xkms change
   first. go-quicbaas re-exports it when the pin (#1389) reaches a tag that
   carries it. Test: an ACME challenge POST whose payload the verifier reads.
3. **ARI and cross-sign on every transport.** The ACME client
   (`sdk/go/xkms/acme`) already aliases go-xkms's client, cross-sign config
   and `ACMECrossSignerFromClient`; add the ARI (`renewalInfo`) client verbs
   by alias and a per-transport test (REST, gRPC, QUIC, MCP, Unix,
   embedded) through the mounted go-xkms module.
4. **Remove QuicBaaS's own ACME (`/api/v1/acme/*`, `pkg/service/acme_service.go`,
   `pkg/server/acme.go`, `cmd/quicbaas/acme.go`).** Held: removed only on the
   owner's word (SPEC row text). Tests: the routes answer 404 and the
   go-xkms ACME mount serves the same flows.
5. **Ship.** The row's PR ticks the acceptance and marks the row shipped in
   `docs/SPEC.md`, and `docs/certificate-authority/` links the go-xkms ACME
   pages (release-readiness rule: documented once, in go-xkms).

## Out of scope

- Any ACME code of go-quicbaas's own: everything is an alias of go-xkms.
- The go-qrdb/go-xkms pin bump itself (#1389).
