## Objective

A delegated embedded client can call the live public operations (for
example `Auth().GetJWKS` and `Auth().GetOpenIDConfiguration`) whatever its
grants; protected Auth and session operations need their mapped permission;
a method missing from both the public set and the permission map is still
refused with `DelegatedOperationUndeclaredError`.

## Slices (once #1845 is on main)

1. Red test: a delegated client with no grants calls `GetJWKS` and
   `GetOpenIDConfiguration` through the embedded transport and gets
   `DelegatedOperationUndeclaredError` (fails on main after #1845).
2. Fix: an explicit public-operation set next to the permission map in
   `authorize.go`, consulted before the zero-permission refusal at
   `embedded_identity.go:173`; map the other registered Auth and session
   operations to the permissions they need.
3. Tests: positive delegated discovery tests on every transport the
   finding names (embedded; the CLI over the quic and REST transports
   through `make integration-test-<feature>`); a coverage test that every
   registered `quicbaas.Auth` handler is classified public or mapped; a
   negative test that an undeclared method is still refused.
