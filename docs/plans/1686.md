# Plan: #1686 SPEC row service-policy, signed policy with one engine

Folds #1350 (its plan, `docs/plans/1350.md`, merged from
`refs/fold/service-policy/row/1350-aq1350`; this plan supersedes it).

## Objective

The Go-coded admission, sandbox, mount, network, trust, communication, role,
lifecycle and spend policies move into one `pkg/policy` engine dispatched by
kind. Policy documents are data: signed through go-xkms, stored in go-qrdb and
verified on load. IAM authorization stays go-qrdb's PDP; no kind decides an IAM
question. go-trusted-platform's rego rules map onto the existing kinds.

## Slices, in order

1. **Engine core** (slice 1, done). `pkg/policy`: `Kind`, `Document`,
   `SignedDocument`, the `Signer`/`Verifier` seam, `Evaluator`, `Engine` with
   map dispatch. `Load` verifies the signature and validates the spec before a
   document is used; unsigned, tampered, wrong-tenant, unknown-kind and
   bad-spec documents are refused. IAM kinds are refused by name.
   Tests: dispatch, duplicate registration, every load refusal.
2. **Sandbox kind** (slice 2, done; its document is the tenant override): `pkg/fleet/sandbox_policy.go` moved with `git mv` into
   `pkg/policy/sandbox`, plus the `sandbox` evaluator over
   `orchestration.ResolveSandboxMode`. Tests: moved resolver test, allow/deny.
3. **go-xkms signer**: adapter from `sdk/go/xkms` Sign/Verify to
   `policy.Signer`/`policy.Verifier` with the tenant key; contract test
   against the embedded go-xkms.
4. **qrdb store**: signed documents in the tenant's qrdb store; reads verify
   on load. Tests over the in-memory and embedded stores.
5. **Remaining kinds, one per slice**: mount, sandbox-network, communication,
   role, lifecycle, spend, admission; each moved with `git mv` from
   `pkg/orchestration`, registered, the old copy removed once callers are wired.
6. **Trust kind**: held (see below) until measured launch lands or a ruling
   moves it in; the row is not shipped without it.
7. **Verbs on every transport**: put, get, list, evaluate on REST, gRPC, QUIC,
   MCP, Unix and embedded through `sdk/go`; `make integration-test-policy`.
8. **gtp rego mapping**: a table in `docs/service-plane/architecture.md` and a
   test per mapped rule. Then the PR marks the row shipped in docs/SPEC.md.

## Trust-tier hold (from #1350, ruling 109 waiver)

`pkg/orchestration/trust_policy.go` (`TrustLevel.RequiresMeasuredLaunch`, used
by `container_attestation.go`) is on the measured-launch path, and SPEC row
`measured-launch` is `planned`. No slice edits `trust_policy.go`,
`container_attestation.go` or `container_trust.go` until that changes. Open
decision for the coordinator: the row's acceptance names trust, so either
measured launch lands first or a ruling moves trust in.

## Out of scope

- IAM authorization (go-qrdb's PDP).
- Rewriting an evaluator: each is moved, not rewritten.
