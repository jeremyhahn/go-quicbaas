# Plan: #1773 built-in role reconcile on a real node (ruling 62(c), amended to (a))

## Objective

Prove on a real go-qrdb node that the tenant SO repairs built-in role drift
through `QRDBRoleStorage.ReconcileBuiltInRoles`. Ruling 62(c) was amended to
(a) in CA m992: the SO runs the reconcile, not the tenant admin, because
`roles:create` is SO-exclusive in go-qrdb v0.51. Then remove the boot-time sweep
(`pkg/server/role_reconcile.go`), which cannot authenticate on v0.51.

## Status: blocked on the go-qrdb pin

main pins go-qrdb v0.30.1-alpha. The issue's route needs v0.51.0-alpha APIs
that v0.30.1 does not have:

- `CreateTenantRequest.AdminUsername` / `AdminCSRPEM` and `CreateTenantResponse.Admin`
  (go-qrdb seeds the tenant's admin and built-in roles itself);
- `Node.ServiceContext`, `Node.AuthMiddleware`, `CertClient.IssueCert`;
- `qrdbtestutil` `TenantHost`;
- `qrdbsdk.PermissionDeniedError`, `qrdbsdk.CrossTenantDeniedError`.

Compiling the finished tests from the train (`pr/1845`,
`pkg/iam/qrdb_role_storage_reconcile_test.go`) against main fails on exactly
these symbols. On v0.30.1 the boot sweep still runs and is still the only path
that repairs drift, so removing it now would take that repair away.

The work is already done on train #1845 (the #1623 / #1816 pin bump), which is
held and not merged:

- `pkg/iam/qrdb_role_storage_reconcile_test.go`: SORepairsDrift,
  NoDriftWritesNothing, TenantAdminIsRefused, SOCannotReconcileAnotherTenant;
- `mapQRDBRoleError` maps both refusals to forbidden;
- `pkg/server/role_reconcile.go` is removed and `iam_init.go` updated;
- `docs/iam/api.md` and `docs/iam/engineering.md` say the SO runs it.

## Slices (once the v0.51 pin is on main)

1. Land the test file and the `mapQRDBRoleError` mapping from #1845, plus a
   revert check (reconcile without the SO context fails).
2. Remove the boot sweep and its four `TestReconcileTenantBuiltInRoles_*` tests.
3. Change the docs from "tenant admin" to "tenant SO".

## Out of scope

- The go-qrdb pin bump itself (#1623 / #1816).
- A go-qrdb permission for the tenant admin (ruling 62(c)=(b), not chosen).
