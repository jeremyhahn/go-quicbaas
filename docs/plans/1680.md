# Plan: SPEC row agent-fleet (#1680)

## Objective

The row's acceptance holds: remote and embedded fleet nodes with mTLS
enrollment, heartbeat and recovery; `fleet serve` and `fleet deploy`, the
node sandbox and the worker image; agent images published to the registry.
Detail lives in `docs/agent-fleet/`. One branch, one PR (#2452).

5. **Worker image contents (#1840, #2222, #1385, #759).** Toolchains for
   trusted-firmware lanes, the pinned gh CLI, the nightly workflow,
   agent images published. Tests: install proofs and buildgates.
6. **Ship.** Tick the row's checklist, mark the row shipped in
   `docs/SPEC.md`.
