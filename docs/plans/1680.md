# Plan: SPEC row agent-fleet (#1680)

## Objective

The row's acceptance holds: remote and embedded fleet nodes with mTLS
enrollment, heartbeat and recovery; `fleet serve` and `fleet deploy`, the
node sandbox and the worker image; agent images published to the registry.
Detail lives in `docs/agent-fleet/`. One branch, one PR (#2452).

## Slices, in order

1. **Fold the open slice PRs and fold refs.** Done: folded at the branch
   base (PR #2321 and every `refs/fold/agent-fleet/*` ref).
2. **Tenant binding (#2233, #1358).** Done. `fleet deploy` binds the tenant
   instead of `context.Background`; the fleet enrollment E2E passes and CI
   runs it. Test: a fleet_deploy unit test that fails without a tenant,
   and `make integration-test-fleet`.
3. **Enrollment claim (#1825, #1776).** Waits on go-xkms#1659 (the SPIFFE
   kind on SignCSRRequest) and on the go-xkms pin bump; not lane work until
   both land. Enrollment requires the issuer-stamped agent claim;
   workstation deploy requests the svc kind via go-xkms SignCSR. Tests:
   enrollment rejects a plain svc SPIFFE cert.
4. **Heartbeat recovery (#1824, #2327).** Done (#1824 and #2327). Repeated
   401 after refresh re-enrolls; the daemon stores its failed state before
   its run error. Tests: daemon heartbeat tests, run with `-count` to prove no flake.
5. **Worker image contents (#1840, #2222, #1385, #759).** The
   trusted-firmware and go-xkms variants are published by their own workflow
   on main. The worker image is published to a public package, and `current`
   moves after a green nightly. The remaining image fixes ride their own PRs.
   Tests: install proofs and buildgates.
6. **Ship.** Tick the row's checklist, mark the row shipped in
   `docs/SPEC.md`.
