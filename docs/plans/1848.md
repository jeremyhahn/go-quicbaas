# Plan: #1848 role List pages cover every role exactly once

## Objective

Paging through a tenant's roles by offset returns every role exactly once.
`MemoryStorage.ListRoles` applied the offset to a slice built from map
iteration, so two offset pages could overlap or leave a role out.

## Slices

1. `pkg/iam/storage_memory.go`: `MemoryStorage.ListRoles` sorts by role ID
   before it applies the offset, the order `ListUsers` uses.
   Test: `TestMemoryStorage_ListRoles_OffsetPagesCoverEachRoleOnce`
   (`pkg/iam/storage_memory_role_paging_test.go`) creates N roles, pages at
   size k, and asserts each role comes back exactly once and in ID order.
   It fails before the fix and passes after, under `-count=30`.

## The QRDB store

`QRDBRoleStorage.ListRoles` asks the qrdb server for each page through
`OffsetWindow`, the same way `QRDBUserStorage.ListUsers` does. The server
sets the order, so the client has no unsorted set to put in order.
Nothing changes in it here.
