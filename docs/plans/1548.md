# Plan: #1548 embedded route-parity ledger, the request-type half

## Objective

Every `sdk/go/client` method that reaches a handler in
`sdk/go/transport/embedded` sends a request type the handler accepts. The route
half of the ledger has landed already (#1569 to #1624, one PR per service). The
1544b type ledger found 28 mismatches. Transaction Execute was fixed by #1624.
The other 27 still fail with `NewInvalidRequestTypeError` on main.

## Slices, in order (each folds a preserved tip from the 2026-10-27 triage)

Each slice cherry-picks the tip's commits onto the row branch, resolves them
against main and keeps the tip's client-over-embedded tests. Every test fails
on main and passes after the fold.
