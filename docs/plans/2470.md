# Plan: epic #2470, default provider accounts and agents (SPEC rows)

## Objective

Draft the owner's product direction as SPEC rows for the owner's approval:
default model-provider accounts per frontier provider, the default Tenant
Agent on its provider's default account, user agents, project agents chosen
at project creation, and session-only agent options. PR #2474 carries the
rows in `docs/SPEC.md` and their lines in `ROADMAP.md`, and the code of the
provider-accounts row, approved as written: every tenant's default provider
accounts, awaiting the credential its user sets at first login.

## Slices, in order

1. SPEC and ROADMAP rows (PR #2474): rows provider-accounts, agents,
   project-agents, agent-sessions; tenant-agent row extended. Docs only: no
   tests; the gates are the docs checks and the lint job.
2. Finish PR #2474: merge `origin/main` (signed merge commit), so the lint
   job's deps-check runs against main's `golang.org/x/oauth2` v0.38.0 and
   `golang.org/x/sys` v0.50.0 upgrades. `make deps-check` fails on the
   pre-merge head and passes after; re-run `make deps-check` and
   `make lint` until green.
3. Default provider accounts (code on PR #2474, the row approved as
   written): the `awaiting_credential` status, frontier providers in the
   provider registry, `SeedDefaultProviderAccounts`, boot and unseal
   seeding, the SDK status constant; unit tests in pkg/orchestration,
   pkg/service and pkg/server.
4. Seeding on tenant creation: CreateTenant tells created-observers; the
   server seeds every tenant created after startup, whatever its isolation;
   unit tests in pkg/iam and pkg/server, and
   `TestAgentAccountDefaultProviderAccounts` proves it on every transport
   with `make integration-test-account`.

Implementation of each other row is its own row issue (#2471, #2472, #2473
and later ones), placed after the owner approves the rows.

## Out of scope

- The agents, project-agents and agent-sessions code, and the tenant-agent
  row: each lands under its own row with its unit and
  `make integration-test-<feature>` tests.
- Any new verb, permission or RBAC change: first login is the existing
  account credential rotate call.
- Changes to rows other than tenant-agent.
