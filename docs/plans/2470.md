default model-provider accounts per frontier provider, the default Tenant

rows in `docs/SPEC.md` and their lines in `ROADMAP.md`.

   job's deps-check runs against main's dependency upgrades; re-run

Implementation of each row is its own row issue (#2471, #2472, #2473 and
later ones), placed after the owner approves the rows.
