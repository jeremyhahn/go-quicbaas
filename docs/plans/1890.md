# Plan: #1890 — a refused quorum submission drops the consumed challenge

## Objective

Codex review 7395 P1 5 on #1845: qrdb deletes a quorum challenge on every
submission, refused ones included. `ShamirShareInput` kept the challenge after
a refusal, so "Request challenge" never came back and every retry answered a
challenge qrdb had already deleted. On refusal the component must clear the
challenge and the signature over it (keeping the username and share), so the
holder requests a fresh challenge.
