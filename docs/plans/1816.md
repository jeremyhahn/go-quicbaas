# Plan: #1816 sdk/go/xkms re-exports the go-xkms signer store

## Objective

go-trusted-platform's `QuicBaaSKeyStore` must implement `xkms.Backend`,
whose `SignerStore() store.SignerStorer` names a go-xkms type the platform
may not import. `sdk/go/xkms` re-exports that type and its constructor so
the platform can declare the method through the SDK alone.

## Slices

1. `sdk/go/xkms/signer_store.go`: alias
   - `SignerStorer = store.SignerStorer`;
   - `NewSignerStore = store.NewSignerStore`.
   `NewSignerStore` takes `(*slog.Logger, storage.Backend)`; the backend is
   already re-exported as `xkms.StorageBackend`. `store.SignerOpts` is already
   exported from `xkms.go` as `xkms.SignerOpts`, so no other options type is
   needed.
   Test `sdk/go/xkms/signer_store_reexport_test.go`:
   - a compile-time check that `xkms.NewSignerStore` has the signature
     `func(*slog.Logger, xkms.StorageBackend) xkms.SignerStorer`;
   - a compile-time check that the alias is the go-xkms interface;
   - `TestSignerStore_IsTheGoXKMSStore`: the constructor is go-xkms's own
     function, and it returns a working store on the memory backend.
   Before the change the test does not compile; after it, it passes.
   Changelog: `changelog.d/1816-signer-store-reexport.md`.

## Out of scope

- Cutting the SDK tag the platform pins: that is a release step, not this
  lane's.
- Changing go-trusted-platform: that is its own repository.
