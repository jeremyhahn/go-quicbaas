# Plan: SPEC row `kms` (#1654)

## Objective

Ship SPEC row `kms`: go-xkms KMS and its backends re-exported through
`sdk/go`, QuicBaaS's parallel key store kept until the owner removes it,
and every KMS verb scoped to the caller's tenant (another tenant's key,
policy or DEK id is not found, #1476). The row's one PR closes #1654 and
marks the row shipped in docs/SPEC.md.
