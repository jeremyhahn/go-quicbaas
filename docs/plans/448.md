# Plan: #448 — no test sleeps

## Objective

Ruling 189 (testing convention "No test sleeps", owner 2026-10-18): one
deliberate sweep in which every `time.Sleep` in a `_test.go` file is replaced
by a bounded polling helper, so a slow runner changes how long a test takes,
never its verdict.

## Shared helper

`pkg/testutil/poll` is a leaf package (imports only the standard library), so
every package can use it from internal tests, including `pkg/security`, which
`pkg/testutil` itself imports. API:

- `poll.Until(t, timeout, cond, msg...)`: polls `cond` until it holds, fails
  the test with `msg` when the bound passes.
- `poll.Wait(timeout, cond) bool`: the non-failing form, for goroutines and
  for callers that assert on the result themselves.

Rules for each replaced sleep (line by line, not mechanical):

- A sleep waiting for background work becomes `poll.Until` on the observable
  the test then asserts (counter, received payload, file content).
- A sleep advancing the clock past a TTL becomes `poll.Until` on the
  synchronous call that observes the expiry; the assertion stays synchronous.
- A sleep with no observable after it ("give goroutines time") becomes a wait
  on the work that goroutine does, or is removed when nothing depends on it.
- An assertion is never relaxed to make it pass (#461's sixth mechanism).

## Slices, in order

1. This plan, `pkg/testutil/poll` with its tests, and `pkg/security`
   (`siem_test.go`, `audit_test.go`, `audit_unit_test.go`, `secrets_test.go`,
   `secrets_unit_test.go`, `coverage_unit_test.go`, `encryption_test.go`).
2. `pkg/catalog/worker_test.go`, `pkg/rag/watcher/watcher_test.go`,
   `pkg/cache/manager_integration_test.go`, then the rest of `pkg/catalog`,
   `pkg/rag`, `pkg/cache`.
3. `pkg/iam`, `pkg/watch` and the remaining `pkg/` and `sdk/` packages.
4. `test/integration/` (cluster, vector, iam, ...).
5. A lint rule (`forbidigo`) against `time.Sleep` in `_test.go`, so the sweep
   cannot decay; `docs/SPEC.md` row note.

Each slice runs the unit tests of the packages it touches through `make`.

## Out of scope

- `time.Sleep` in non-test code.
- Changing production code to make it observable, unless a test has no other
  observable; such a change is called out in its commit.
