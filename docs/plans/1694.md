# Plan: SPEC row software-factory (#1694)

## Objective

The Software Factory runs on QuicBaaS: projects, accounts and the SDLC
module carry triage, task workers, review and merge on the deployment; every
company agent has a standing MCP principal; every deterministic step of the
manual factory (the LSF runbook) is automated and agents wake only for
judgement. Detail: `docs/software-factory/`, `requirements/`. One branch
(`row/1694-software-factory`), one PR, which marks the row shipped in
`docs/SPEC.md`.

## Slices, in order

1. **Folds.** Merge PR #2466 (the SDLC binding profile and public summary in
   `docs/SPEC.md`); merge `refs/fold/software-factory/row/805-aq805`
   (#805: `pkg/sdlc` and `pkg/fleet` under `pkg/orchestration`, with the
   package-tree guard test). Tests: the fold's own guard test; unit tests of
   the moved tree; `go build ./...` and the integration vet.
2. **Agent principals (#1129, #1139).** A standing mTLS MCP principal per
   company agent in the automatethethings tenant; custody of agent tokens,
   AI-account tokens and signing keys. Tests: IAM unit tests; MCP
   integration target with the principal's certificate.
3. **Parity: triage and brief (#2358, #2359).** Runbook steps 0-2 as SDLC
   jobs. Tests: SDLC unit tests per step; `make integration-test-sdlc*`.
4. **Parity: lanes, placement, seats, verify (#2360, #2361).** Steps 3-6.
5. **Parity: epic PRs, trains, CI, review, merge (#2362-#2364).** Steps 7-11.
6. **Parity: release, cleanup, rollup and tokens (#2365-#2367, #2375).**
   Steps 12-13, status rollup, progress-vs-spend with baselines, alerts and
   budget stops.
7. **SDLC profile (#2368)** and the external-issue approval gate (#2417).
8. **Exit gate (#2369).** One P1 project runs a full day with no LSF script;
   the PR marks the row shipped in `docs/SPEC.md`.

Each slice adds a test that fails before and passes after, and runs the unit
tests of the packages it touches and the integration targets of its features.

## Out of scope

- Changes to the LSF scripts themselves (they retire after the exit gate).
- Protected CI paths (`.github/`) unless a slice's brief allows them.
