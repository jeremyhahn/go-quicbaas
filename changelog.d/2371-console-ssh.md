### Added

- The web console's SSH Keys page reaches every SSH operation the SDK builds. A key's View dialog loads the key's details and its exported public key line and fingerprint, and still shows the listed public key if the export fails. A new Sign action signs a hex digest with the key and shows the signature format and the base64 signature. Each known-host pin has a Verify action that checks a presented fingerprint and says whether it matches the pin, does not match, or has no pin. A new Authorized Keys panel lists, adds, shows and removes the stored authorized_keys entries for the active scope and owner, formats a public key into an authorized_keys line and checks which entry a fingerprint matches. A connection without the SSH client shows the panel as not available (#2371).
