### Added

- The web console has a new Agents page (Software factory, after Accounts) that manages the tenant's Agent catalog. The Agents table lists each Agent's id, name, roles, backend, model and last update; New agent creates one from an id, name, one or more roles, backend and model, with an optional description and reasoning effort; Edit loads the stored Agent and saves it back with the form's fields merged on, so the settings the form does not show are kept; Used by lists what references the Agent; and Delete asks first and shows the server's refusal when the Agent is still in use. The Agent pools table does the same for pools, whose members are chosen from the listed Agents and ordered with move up and move down, since the order is the failover chain. A connection without the Agent catalog shows the page as not available (#2371).
