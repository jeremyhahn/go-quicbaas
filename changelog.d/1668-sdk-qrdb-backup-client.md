### Added

- The Go SDK re-exports go-qrdb's backup service: `client.Storage().QRDBBackup()` returns `quicbaas.QRDBBackupClient` (go-qrdb's `BackupClient`: create, list, get, delete, restore and verify backups) over the client's QRDB transport, with the `QRDBBackupRequest`, `QRDBBackupInfo`, `QRDBRestoreRequest`, `QRDBRestoreResult` and `QRDBVerifyResult` types. The embedded transport takes the service as `QRDBEmbeddedServicers.Backup`. Over a network transport `CreateBackup` returns `Unimplemented` because a quicbaas node keeps go-qrdb backups in memory only (use `sdk/go/client/backup` for durable backups), the `WithAuthToken` bearer rides every call over gRPC and Unix, and over REST, QUIC and MCP a client with credentials gets `Unimplemented` from `QRDBBackup()` (#1668).
