# Orchestration Examples

Examples demonstrating QuicBaaS multi-agent orchestration workflows.

## Examples

### [tictactoe](tictactoe/)

Multi-agent JavaScript game development using Codex for coding and Ollama for planning/review. Demonstrates constrained workflow mode with persistent coding sessions.

## Running

Each example includes a `run.sh` script and a `workflow.yaml` definition. Ensure `quicbaasd` is running with the required backends configured before executing.

```bash
./examples/orchestration/<example>/run.sh
```
